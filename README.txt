SHUKOOR & HANA — WEDDING INVITATION WEBSITE

Files:
- index.html: invitation page
- style.css: responsive black, antique-gold styling and animations
- script.js: opening scroll, gold particles, reveal effects and calendar links
- assets/couple-photo.png: generated couple portrait provided for this invitation

PREVIEW:
Open index.html in a browser. Internet is needed for the Google Fonts and Google Maps/Calendar links.

PUBLISH WITH GITHUB PAGES:
1. Sign in to GitHub and create a new public repository (for example: shukoor-hana-invitation).
2. Upload all files and folders in this package, keeping the assets folder structure.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch; select main and / (root), then Save.
5. GitHub will provide a public website URL after deployment.

NOTES:
- Current invitation uses only the confirmed information supplied so far.
- Venue map link searches for the venue name; please verify the exact pin before sharing.
- No reception, family residence, siblings, or contact number has been added because those details were not supplied.
- The calendar event is set for 9:00–11:00 AM as a placeholder duration; change it if the ceremony ends at a different time.
